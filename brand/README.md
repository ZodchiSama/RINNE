# Rinne brand assets

The Rinne mark is the Wheel of Reincarnation (輪廻の輪), a nod to the manga RIN-NE. Its rim is one
arrow chasing its own tail: when a show ends, the next one is reborn in its place. Inside are 12
beads, a banded inner ring and six spokes.

All PNGs have transparent backgrounds unless noted. Use `dark-mode` files on dark backgrounds and
`light-mode` files on light ones.

| Folder | What's inside |
|---|---|
| `app-icon/` | Dark rounded tile, 16–1024 px, plus `rinne-icon.ico` (16–256). Sizes 16–48 use the simplified wheel. `rinne-badge-round-512.png` is a round in-app badge. |
| `mark/` | The wheel alone: gradient (dark/light mode), one-color white and black. `mark-simple-*` is for small sizes (≤48 px). |
| `title/` | Text only: `RINNE`, and `RINNE` with 輪廻 underneath. |
| `logo/` | Full logos: stacked (wheel above the name) and horizontal (wheel left, name right). |
| `japanese/` | 輪廻 leads, with RINNE in support: title, stacked, horizontal and vertical (tategaki). |
| `banner/` | GitHub social preview 1280×640 (EN and JP), README header 1600×500 (dark/light). These have backgrounds. |
| `source/` | GIMP masters (`.xcf`) for the mark, app icon and stacked logo, plus the scripts that build the other layouts. |
| `concepts/` | Earlier alternatives: the first wheel, Ensō and Tomoe. |
